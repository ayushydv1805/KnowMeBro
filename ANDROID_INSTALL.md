# Install KnowMeBro on Android

## Option A — Install the APK

1. Download the **KnowMeBro APK** from the successful **Build Android APK** workflow artifact in GitHub Actions.
2. On your Android phone, open the downloaded APK.
3. If Android asks, allow your browser or file manager to install unknown apps for this installation.
4. Tap **Install**, then open **KnowMeBro**.
5. Sign up or log in to your KnowMeBro account.

The APK uses the hosted KnowMeBro app and its Supabase backend, so an internet connection is required. Sign in to the same account on every device to retrieve account-linked quizzes and cloud-stored quiz attempts. Closing the app does not delete cloud data. Local-only drafts remain on the device unless published/saved to the account. Cloud retention depends on the account and backend remaining available; it cannot be guaranteed literally forever.

The debug APK is for direct installation/testing. It is not a Play Store release and is not signed with a production release key.

## Option B — Install from Chrome

1. Open the deployed KnowMeBro website in **Google Chrome** on Android.
2. Open Chrome's **⋮** menu.
3. Tap **Install app** (or **Add to Home screen**, depending on the Chrome version).
4. Confirm. KnowMeBro will appear on your home screen and launch in its own app window.

Both options are free and do not require a Play Store account.
